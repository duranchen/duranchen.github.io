# 如何开始从0开始写作

1. 日记
2. 文章
3. 文案

## 写作的本质——销售

销售的是什么？

作者销售价值。  
读者用注意力和阅读时间购买。

为什么看你的文章？

第一眼看到价值，

为什么要继续阅读下去？

具体直观的价值。

我是不是现在要花5到10分钟读完它？

作者销售的是文章的价值。

## 文字背后的人

1. 读者
2. 作者

### 读者

年轻，压力大，迷茫，没有压力，缺钱，特别痛苦，觉得出路。

所有特别看重技能，方法，思维方式。

解决对方的痛苦，带去愉悦。

需要了解对方的需求

### 作者

文字要有人情味，你是什么样的人，你的文字就是什么味道。

理性的人  
感性的人

不仅做信息的传递，情感的传递。

### 人的认知模式

1. 我们在故事中思考
2. 集中注意力，其他东西视而不见。
3. 情感决定一切事物的意义
4. 人类依靠具体的形象来思考
5. 大脑思考按照因果关系来构建
6. 大脑厌恶随意，更喜欢有规律的模式

### 写作的方法论

1. 写作的模式  
   故事+干货+人情味（和朋友对话）  
   讲故事的七条方法  
   只讲自己相信又打动自己的事  
   让读者有兴趣读下去最重要  
   不要讲废话，讲核心  
   一次只讲一个主题  
   结论还要写原因  
   一定要加入情感  
   将故事的4条技法  
   时间顺序  
   倒着写  
   反着写  
   标题应该如何写  
   标题作用，让人阅读第一句话。  
   呈现价值和好处  
   引起读者情绪变化  
   如何写好第一句话

用不同的词和不同人沟通？  
 目标感比较强，直接列重点  
 情感，塑造轻松场景  
 逻辑，数据，列表  
 保守，口碑
